# Open Anywhere 宣传片脚本

> 版本：v0.1 · 2026-10-25
>
> 用途：黑客松路演、项目主页、社交媒体。本文是可执行的分镜，不是文案稿；现场同期声优先，台词只规定"要说到的事"，不逐字背诵。

## 1. 基本信息

| 项目 | 内容 |
| --- | --- |
| 片长 | 主版 90–100 秒；短版 30 秒 |
| 画幅 | 16:9 主版，9:16 从主版重新裁切 |
| 声音 | 现场同期声 + 少量轻音乐，不用旁白（片尾字幕除外） |
| 核心原则 | 拍"使用"，不拍"功能"；用反应代替解释 |
| 一句话定位 | 说出你的需要，让应用在身边的屏幕上诞生 |
| 聚会版表达 | 一句话，把客厅变成聚会现场 |
| 收尾字卡 | 有块屏幕，就能开场 |

**要证明的三件事：**

1. **一句话就能定制**：四个人、玩法、目标屏幕，都在一句话里说清楚。
2. **AI 在现场，不只在后台**：它主持、报分、接话，是牌桌上的第四个声音。
3. **应用跟着人走**：换一块屏幕，不用重做、不用重进。

## 2. 人物与场景

| 角色 | 定位 | 在片中的作用 |
| --- | --- | --- |
| 韩鲁鹏 | 发起者 | 对灵矽提出需求，决定开局与换屏 |
| 张之阳 | 嘴硬 | 先领先、后被逆转，贡献"被击败"和"换屏"两个梗 |
| 邓军辉 | 黑马 | 赢下冲击波（暂定，以现场实际结果为准） |
| 黄梦玉 | 起哄 | 补刀、制造笑声，推动节奏 |
| 灵矽 | AI 主持 | 第四个声音，不露脸；台词短、有反应，不播报 |

场景：

- **A 客厅**：主场景，沙发、电视、灵矽设备、零食饮料。
- **B 卧室或书房**：第二块屏幕，距离客厅有一段可见的走廊。
- 两个房间都要能投屏，同一个局域网，Render 地址可达。

> 以上角色分工是建议。谁先领先、谁翻盘、谁提换屏，以现场真实反应为准；剪辑只放大，不编写。

## 5. 台词与拍摄原则

**台词**

- 每句不超过 12 个字，方便字幕和短视频传播。
- 不解释产品，只表达感受。观众不需要知道"这是 Agent 生成的"，只需要看到"他们真的玩起来了"。
- AI 台词要有反应，不要播报腔。报分可以说得短、带一点情绪。
- 允许沉默、抢话、重叠说话。这些比整齐的台词更可信。

**不拍**

- 不拍代码、终端、构建日志。
- 不拍需求澄清的长对话，最多一句。
- 不拍产品界面讲解、不拍手机操作。
- 不拍"我们做了一个平台"式的自我介绍。
- 不用旁白解释功能。字幕只负责三句话：四个人、一句话、换屏。

**导演提示**

- 拍反应，不要一直拍屏幕。观众看人脸就知道好不好玩。
- 让 AI 的声音先于画面出现，观众会先"听到"它，再"看到"它。
- 失败和等待也是素材。真实的 9 秒等待，比"三秒生成"的假象更可信。
- 前 3 秒必须有人脸和冲突；之后每 4–6 秒换一次镜头。

## 6. 拍摄清单

**场地与设备**

- [ ] 客厅、卧室（或书房）各一块可投屏的屏幕，同一局域网。
- [ ] 灵矽设备（或模拟硬件）+ 投屏服务 + Render 服务，提前跑通。
- [ ] 冲击波应用已就绪；四人大富翁现场构建，确认构建耗时。
- [ ] 领夹麦 ×4，或吊麦 + 一支备用；单独录 30 秒环境音。
- [ ] 至少两机位：主机位全景 + 屏幕/反应特写。手机可作第二机位。
- [ ] 零食、饮料、抱枕、拖鞋。要生活感，不要摆拍。

**现场检查**

- [ ] 四个玩家的名字在屏幕上都能出现。
- [ ] 两个屏幕显示的是同一个应用、同一局进度（换屏的关键证据）。
- [ ] AI 语音在环境噪声下能听清；听不清就靠近设备说，不要后期假配。
- [ ] 冲击波的规则能用一句话说清，并做成字幕。
- [ ] 构建失败时有备用方案：保留真实重试，或改拍已就绪的应用。

| 调色 | 暖色、生活感；不要科技蓝和粒子特效 |
| 片尾 | 标注构建未加速、模拟硬件（如适用），这是可信度的一部分 |

## 8. 真实性与风险

1. **输赢必须真实发生。** 如果彩排没打出逆转，重开一局，不演剧本。观众能看出假的高兴。
2. **换屏必须证明是同一个应用。** 拍下第一块屏的界面特征，第二块屏要出现同样的特征。如果只能重新打开，台词改成"投到另一块屏"，不要说"接着玩"。
3. **"四人"必须真有四个玩家位。** 屏幕上四个名字都要点亮。如果实际只有三个人，台词就别说"四人"。
4. **构建时间不可控。** 超过 60 秒就用冲击波填满等待；构建失败可以保留一次真实重试，但不要超过一次。
5. **AI 不假配。** 如果现场识别不稳定，减少 AI 发言，也不要用后期配音冒充。
