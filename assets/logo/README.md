# open anywhere logo

## 文件

| 文件 | 用途 |
| --- | --- |
| `open-anywhere-logo.svg` | 横向组合，浅色背景 |
| `open-anywhere-logo-dark.svg` | 横向组合，对比色/深色背景 |
| `open-anywhere-avatar.svg` | 不带文字，组织头像 |
| `open-anywhere-avatar-1024.png` | 头像上传导出，1024 × 1024 |

## 颜色

| 名称 | 色值 |
| --- | --- |
| Ink | `#0E1116` |
| Teal | `#00A88F` |
| Teal（深色背景） | `#00C2A8` |
| Cream | `#F5F3EE` |

## 使用

- GitHub 组织头像只接受 PNG/JPG/GIF，不能直接上传 SVG；上传 `open-anywhere-avatar-1024.png`，位置是组织 Settings → Profile → Profile picture。
- 浅色背景用 `open-anywhere-logo.svg`，深色背景用 `open-anywhere-logo-dark.svg`。
- 不要拉伸、旋转或改变标记比例。
- 字标基于 Manrope Medium（SIL Open Font License）转曲，SVG 不依赖字体文件。
