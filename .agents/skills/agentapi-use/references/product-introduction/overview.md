# 产品概述



最近更新时间: 2026-10-14 11:36:18

AgentAPI 是在托管环境中运行的可配置智能体框架。适合长时间运行的任务和异步工作。

## 使用方式

AgentAPI 支持 Portal 可视化使用和 API 方式使用，两种方式都可以配置智能体、运行任务并查看结果。

| 使用方式       | 适用场景                                                                                                 | 入门指南                                                                  |
| ---------- | ---------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| Portal 可视化 | 快速上手，或无需编写代码即可配置、测试和调整智能体。                                                                           | [在 Portal 中构建](../quick-start/portal.md)  |
| API        | 将 AgentAPI 集成到自有智能体产品或业务系统，通过代码管理配置、提交任务并处理结果。支持直接发送 HTTP 请求或使用 SDK。API 兼容 Claude Managed Agents 协议。 | [通过 API 构建](../quick-start/quickstart.md) |

可以先在 Portal 验证配置，再在代码中引用已有智能体和环境。

## 采用条件

适用于需要以下能力的任务：

* **长时间运行的执行**： 运行数分钟或数小时、涉及多次工具调用的任务
* **云基础设施**： 预装软件包并具备网络访问能力的安全沙箱
* **自托管执行**： 在您控制的基础设施上运行沙箱，以满足合规性或数据驻留要求
* **最少的基础设施**： 无需自行构建智能体循环、沙箱或工具执行层
* **有状态会话**： 跨多次交互持久保存的文件系统和对话历史
* **定时执行**： 通过定时部署按 cron 计划定期运行智能体

产品的配置对象、会话关系和任务执行流程见[基本概念](concepts.md)。

## 应用责任

AgentAPI 管理执行过程；应用校验业务用户与资源归属，保存任务与会话的关联，处理业务工具和审批，并验收结果。自托管模式下，worker 的运行、隔离与清理由部署方负责。
