# AgentAPI 正式发布



最近更新时间: 2026-10-19 15:00:06

一场直播结束后，内容团队需要把数小时素材整理成可供编辑挑选的片段和传播文案。一批业务材料提交后，金融机构需要逐份核对信息，找出缺失与差异，并保留依据。一次业务告警发生后，运维团队需要联动不同系统，结合现场信息与历史经验持续排查。

这些工作往往跨越专业分工、业务系统和执行环境，需要从接收任务、分析问题一路推进到交付结果。要让 AI 承担这样的工作，开发团队除了接入模型，还需要解决执行环境、业务工具接入、任务状态管理和结果交付等问题。

**七牛云 AgentAPI 正式发布，为企业 Agent 应用提供托管执行与管理能力。** 作为通用的托管智能体框架，AgentAPI 支持开发者按需配置智能体、连接工具，开展多步骤长任务与异步工作，把更多精力放在产品体验和任务效果上。

## 01｜从具体业务出发，让 Agent 承担连续工作

从云端编码智能体、个人智能助理到企业业务助手，企业开发者可以基于 AgentAPI 构建不同类型的 Agent 产品。面向内容媒体、金融服务、企业智能运维等领域，AgentAPI 为跨系统、多步骤的业务任务提供执行与管理能力。

### 内容媒体：把长音视频素材转化为可用的内容材料

一场访谈或直播结束后，哪些内容值得传播，如何为不同渠道准备标题和摘要，往往需要编辑反复查看素材。接入音视频转写、媒资检索与处理工具后，Agent 可以整理字幕、划分主题、筛选候选片段。&#x2A;*整理结果包括带时间码的内容索引、剪辑清单和传播文案草稿，供编辑检查和使用。** 团队还可以将栏目风格、选题要求和发布规范配置为可复用的技能，让后续内容整理沿用统一的工作标准。

### 金融服务：批量核对业务材料，形成有据可查的检查结果

面对合同、业务报表和补充附件，业务人员需要核对名称、日期、金额及附件要求，整理缺失项与不一致之处。开发团队可以按照既定检查规范配置 Agent，让它读取文件、提取关键字段、交叉核对信息。&#x2A;*检查结果包括字段汇总表、差异清单和待补充事项，并标注来源位置，供工作人员复核。** 材料补齐后，可以继续检查未解决的问题，更新检查结果，推进后续业务处理。

### 企业智能运维：联动内部系统，让历史经验参与故障排查

业务接口突然变慢，原因可能涉及应用变更、数据库查询、资源负载或下游服务。排查需要查询多个系统，也依赖团队对业务架构和历史故障的了解。接入内部监控、日志和变更记录等工具后，Agent 可以查询相关指标、检索异常日志、执行授权范围内的诊断命令，逐步整理异常时间线、可能原因、待验证事项和处置建议。

**长期积累的运维经验，也可以成为下一次排查的依据。** 配置记忆存储，并由支持记忆同步的自托管执行器接入后，企业可以保存系统依赖、已确认的故障原因、有效的处置步骤和排查注意事项。后续任务按需引用这些资料，结合当前现场信息展开分析，减少重复摸索排查路径的工作。

## 02｜连接现有工具，在合适的环境中执行

自行搭建 Agent 服务，团队需要在业务功能之外维护执行调度、会话状态和结果回传。AgentAPI 托管这些共性能力，企业可以把开发工作集中在业务规则、工具接入和结果验收上。业务要求可以通过智能体配置落实。开发者可以选择运行时和模型，设定任务目标与输出要求，根据所选运行时组合内置工具、自定义工具及远程 MCP 服务，并通过 Agent Skills 复用操作说明、处理脚本和辅助文件。

执行环境也支持按需选择。希望快速启动，可以使用七牛云提供的云端沙箱，配置所需软件依赖与网络访问策略，开展文件处理、代码执行等工作。对于需要周期执行的内容整理、材料汇总或服务巡检，还可以配置定时部署，让 Agent 按计划启动工作。

需要访问内部系统或复用既有执行资源，可以采用自托管执行方式，在自有基础设施中部署执行器（worker）。例如，企业智能运维中的内网查询和诊断操作，可以封装为 worker 的自定义工具，按照企业自身的权限与审计要求执行。worker 将执行结果回传，由 AgentAPI 继续组织模型分析与任务推进。任务输入及工具结果仍会经过 AgentAPI 和模型服务，企业可以据此规划接入范围。

## 03｜可视化 Portal 与 API，两种方式按需选择

AgentAPI 提供可视化 Portal 和 API 两种接入方式，团队可以根据使用需求选择，也可以结合使用。两种方式可以复用同一套智能体和环境配置，支持可视化操作与程序调用协同使用。

**通过 Portal，可视化配置和运行任务。** 使用已有工具和环境时，可以直接在 Portal 中配置智能体、提交任务并查看结果，无需编写 API 调用代码。需要访问内部系统时，可以接入相应的自定义工具或 worker。团队可以在界面中查看回答、工具调用和执行轨迹，下载生成的文件，并按业务要求调整配置。

**通过 API，构建 Agent 产品或集成到业务系统。** 开发者可以通过 HTTP 请求或 SDK 管理智能体和环境、提交任务、获取执行进度和文件产物，为自己的产品设计交互与工作流程。内容团队可以在媒资平台中提交素材、查看候选片段；运维工程师可以在告警页面发起排查、检查执行记录并补充现场信息。Agent 的工作由此融入已有业务入口。
