# 在 Portal 中构建



最近更新时间: 2026-10-13 15:31:05

[AgentAPI Portal](https://portal.qiniu.com/agentapi) 适合快速上手，以及无需编写代码即可配置、测试和调整智能体的场景。通过可视化界面选择配置、发送任务并查看结果，也可以先验证配置，再通过 API 接入应用。首次使用时，按页面引导创建 API Key；地域与鉴权说明见[接入准备](access.md)。

## 配置智能体

从“快速开始”选择模板，或在“Agent”页面创建智能体，配置以下内容：

* 运行时、模型和系统提示词：选择执行引擎与模型，定义任务要求和输出约束。
* 工具和 MCP：配置内置工具、自定义工具或远程 MCP 服务；所需凭证在创建会话时关联。
* 技能：附加已上传的技能，复用任务说明和辅助文件。

再选择或创建环境，设置运行方式、网络与软件依赖。资源页面提供“API 调用示例”，便于将已验证的配置用于代码。

## 测试智能体

“快速开始”按创建智能体、配置环境、创建会话、发送消息四步完成一次测试。也可以在“会话”页面引用已有智能体和环境，新建测试会话。

发送消息后，在会话详情的“对话”中查看回答与工具调用，“轨迹”中检查事件和停止原因，“文件”中下载产物；需要完整记录时，使用“Raw JSONL”导出。

会话空闲只表示当前执行停止，仍需核对回答和产物是否符合任务要求。调整智能体后，创建新会话验证新版本。

## 在代码中复用配置

配置验证通过后：

1. 从 Portal 记录智能体 ID、版本和环境 ID。
2. 在应用中[创建会话](../development-guidelines/sessions-and-tasks/session.md)时引用这些配置，使用同一地域的服务地址和已绑定 Key。
3. 按[通过 API 构建](quickstart.md)中的 HTTP 或 SDK 方式，在代码中发送任务并获取结果。

## 配置 Webhook 通知

在“服务设置 → Webhook”中为当前地域创建通知端点、选择事件，并保存一次性签名密钥。随后可在列表管理订阅、启停和密钥轮换；“API Key”入口独立管理模型调用凭证。租户身份由服务端自动维护，无需填写内部 ID。接收服务的验签、可靠确认及失败恢复见 [Webhook 通知](../development-guidelines/data-and-integrations/webhooks.md)。
